# ProductInventory - Aplicación BackEnd en Springboot

Este es el repositorio del frontend de la aplicación **ProductInventory**, desarrollado en Java y MongoDB. Aquí encontrarás los pasos necesarios para instalar, configurar y ejecutar la aplicación correctamente.

Requisitos previos:

- Asegúrate de tener instalado:
Java JDK 17
Maven 3.8+
IDE como IntelliJ IDEA

1.Ejecutar los siguientes comandos en la terminal:
- mvn clean install
- mvn test ó (Desde el IDE ejecuta la clase principal de las pruebas unitarias ProductInventoryApplicationTests.)
- mvn spring-boot:run ó (Desde el IDE ejecuta la clase principal ProductInventoryApplication.)

2.Una vez la aplicación este ejecutada use la interfaz de usuario desarrollada en React.
Para mas información: Repositorio de la UI en React (https://github.com/JamadoSENA/FrontEnd-React.git)
